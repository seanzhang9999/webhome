# 健联体可信空间演示

入口：`../../awiki-chronic-demo.html#/solutions`。沿用 V5.5 的角色/空间切换、事项/资源/空间/方案、共同工作对象与私人 AI 工作面架构。旧版留在 `awiki-chronic-demo-legacy-20261103.html`。

## 走完演示

1. 家医管理空间：继续 → 患者照护授权 → 家医与患者分别确认管理包 → 患者测量回执与运营随访回执 → 家医异常复核 → 患者反馈 → 周期复评 → 双方确认下一周期 → 家医启动新周期。
2. 科研空间：请求方与审核方确认委托 → 双方确认动态本体口径 → 项目授权核验、患者独立参与确认 → 数据审核方计算 → 输出审核 → 请求方验收和下载。心电与脑机示例使用独立状态。
3. 反例：选择4条小样本，输出必须驳回；改为48条后重新确认与计算。原始患者名单请求会被阻断。
4. 暂停、版本修订和授权撤回会阻断后续步骤。家属共享独立开关；私人笔记按角色和空间隔离显示。

顶部切换模拟角色和空间。键盘 N 继续，R 打开当前工作对象。设置中可重置本页演示；原版状态使用不同存储键，不受影响。

## 实现边界

这是公开的浏览器本地演示，全部角色、数据、授权和回执均为合成示例。角色切换和界面筛选不是安全边界；同一浏览器可查看底层本地状态。不要输入真实健康或身份信息。没有真实模型、ANP 身份服务、设备、医疗机构、山东大学科研系统或中电数据平台连接。

“中电数据服务有限公司平台底座 + ANP + Agent + 动态本体”为拟合作架构。具体数据目录、接口、部署域、授权治理、受控计算和输出审核能力须与平台方验证。本体不授予权限；照护授权不自动继承为研究授权。最小样本10与3次查询预算仅是演示策略，不构成完整隐私保护方案。

原始内容依据用户提供的三张健康助手/家庭群概念图、《健康管理app1024(1).pdf》和用户关于家医端、心电/脑机项目的描述；视觉与叙事参考《向量共识_ANP_AWiki_公司与方案介绍_V17_科研多边协同精简版.pptx》。原始附件及方案PPTX作为本地交付，不随本网页公开上传。
