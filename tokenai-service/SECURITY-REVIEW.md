# TokenAI 公网启用安全审查

日期：2026-10-28。范围：GitHub Pages 到独立 TokenAI 后端、Pi 到 TokenX 的信任边界。
本文件不包含凭据。审查由本任务实现者进行；不是第三方审计。

| 边界 | 控制与证据 |
|---|---|
| 公开静态页面到财务身份 | 本地角色选择不授权；运维创建账号，scrypt 密码哈希，账号禁用即失效；HTTP 测试验证匿名拒绝 |
| 跨域登录 | 一次性授权码、PKCE、精确 origin、窗口 source/state；重放与错误 origin/verifier 测试通过 |
| 浏览器到业务事项 | 每次请求校验令牌、租户和成员；跨租户读取测试通过，令牌不放 URL；记住会话按下述规则存储 |
| Pi 到宿主 | 关闭自动发现扩展/上下文及所有宿主工具，仅注册应用工具；实际 DeepSeek 动态工具调用已验证 |
| Pi 到业务写入 | 明确白名单和实时 schema；写入默认关闭，发起人确认具体参数；超时及重启不重放 |
| 附件 | 随机本地标识、事项校验、10 MiB 限制、0600；内容不进入工具预览；MCP 字段映射必须实测后配置 |
| 远程任务查询 | 只允许本事项创建/运维核验关联的运行标识；未知标识拒绝测试通过 |
| 运行身份 | 独立 tokenai 用户，systemd 禁止提权、限制文件系统写入、只监听回环 |
| 模拟与真实数据 | 真实聊天独立后端持久化；演示重置保留真实消息，浏览器回归测试通过 |
| 凭据与日志 | 受限环境文件、响应脱敏、无请求正文日志；测试覆盖已知密钥和 Bearer 脱敏 |

当前允许公开启用：登录页、状态与基本 DeepSeek 聊天。生产 TokenX 接入须取得有效受限
凭据后，完成发现及只读调用检查；写工具及分享默认不公开启用。未完成真实业务验收的
功能必须显示未开放。现有工具能否提供完整报销台账和到账信息仍需服务方契约证据。

用户随后提供了明确指定的调用凭据，已存入受限配置并完成实际初始化、发现和 scenario_list
只读调用，可启用三个只读工具。实际 schema 中 scenario_result 的 include_share 参数
被约束为 false，防止绕过单独分享确认。没有执行上传、审核、取消或分享业务写操作。
已从两个正式页面验证 Pi 实际调用 MCP 的只读闭环，并精确清理临时验收账号、消息和会话。

工单查询扩展审查：用户明确要求直接查询日期范围内的合同付款审核明细。已核对服务端
schema，新增工具为 scenario_work_orders（列表）和 scenario_work_order（单据详情）。
工单明细 include_share=true 会签发一次性链接，故仍强制拒绝。通过受限环境配置将
TokenX 工单数据范围绑定到现有获授权财务组织；其他 tenant 既不注册工具，也不能绕过
scope 调用。列表日期有效性、范围、分页大小校验及跨组织拒绝用例通过。12 项定向
测试通过；真实 DeepSeek 已完成按日期/类型列出工单、再以 subject_id 查询详情，未
生成写操作。未放宽旧运行工具的 run_id 关联限制，未开启审核、上传或分享。
生产 HTTPS API 的隔离测试验证旧会话历史不会阻止新能力，且未操作真实固定事项。

记住登录及报告入口审查：用户要求 Demo 免去反复输入。记住登录为明确勾选、默认开启的
7 天可撤销会话；浏览器仅保存账号名和登录令牌，不保存密码或 MCP 密钥。令牌时长由
服务端授权码偏好绑定，过期、禁用及注销检查不变；退出会清理缓存。CORS 继续只信任
两个既有源，认识到同源其他 GitHub Pages 仓库属于相同浏览器存储边界。偏好表为独立
新增表，保留旧 codes 五列，以便旧版本回滚后仍可签发授权码。

工单 HTML 入口仅提供静态登录外壳，数据和导出 API 均验证身份与 TokenX 连接组织；
subject_id 严格校验为 UUID。不会请求用户提供的 localhost、任意主机或上游 URL。
MCP 原控制台和报告链接改为本站入口，结果明确标记为结构化导出，既不签发分享，也不
宣称获得了上游原文件。响应强制下载和类型校验，展示时转义所有业务内容。
15 项定向检查通过，包含七天记住/取消勾选、刷新恢复、退出清理、旧表兼容、跨组织
报告拒绝、原 localhost 链接转换、实际浏览器下载与来源标识。

财务经理私人伙伴审查：采用独立 Pi 会话，工具集合为空，快照仅来自当前用户有权读取
的事项可见消息，不读取其他人的私人建议。API 从登录身份确定 user_id，忽略伪造的
查询参数；同事项不同成员仍各自持有私人建议，跨组织无成员时返回 404。结果不进入
共享消息或共享事件流。并发最多 3 个建议任务，同一用户/事项仅一个，主聊天未完成
时等待，未变更时缓存，错误不无限自动重试。真实 DeepSeek 会话验证活动工具数为 0。

Markdown 使用精确版本本地依赖构建，并在插入 DOM 前经 DOMPurify 语义标签白名单
净化；不允许脚本、图片、表单、样式和 DOM-clobbering 属性。测试覆盖标题/表格/代码
渲染、脚本与 javascript 链接拒绝、旧业务链接转换、建议自动更新与私有数据隔离。
18 项定向检查通过，生产依赖审计 0 vulnerabilities。用户明确要求的既有演示账号
口令调整仅作用于该账号，保留其他账号创建规则及已有会话，实际口令不记录于此。

私人问答扩展：采用单独的 companion_questions 表，API 仍按当前身份和事项成员资格
查询，不信任请求中的其他 user_id。问题长短、唯一请求标识和请求频率均受限；同一
用户的问答串行执行。上下文将主聊天、自动分析和自己的历史问答分别标注，仍使用
无工具 Pi 会话。问题及回答不进入主群，也不改写自动分析；中断请求不自动重放。
19 项定向检查通过，含问答隔离/去重/历史、自动分析不被覆盖，以及 250 个流式事件
下避免整段历史重复解析的浏览器回归。保存文件和复制是用户显式动作，不生成新的
分享链接或 URL 令牌；下载 Blob 退出即清理，异步返回仍核对当前登录上下文。

2026-10-28 验证记录：10 项定向测试通过，包含浏览器与 HTTP 检查；实际 DeepSeek 文本
和动态工具调用通过（工具返回 fixture，未声称是公网 TokenX 验收）。官方 npm registry
的生产依赖审计为 0 vulnerabilities。Pi 引用的 undici 8.12.1 存在已知问题，本项目通过
精确 override 锁定 8.12.3，升级后相关测试通过。源码凭据扫描未发现受限配置中的实际密钥。

独立公网服务的 HTTPS/Nginx/systemd/浏览器登录及真实模型消息已验证；临时验收租户、
消息、令牌与会话均按精确标识清理，无 TokenX 业务写入。

新增代理适配通过错误凭据 HTTP 401 实测，拒绝跨源重定向的测试通过。现有本机出口
代理只用于 MCP 客户端，保留 TLS 校验。源页面跨站真实服务测试已通过；GitHub Pages
发布后，正式页面也已完成无源码覆盖、无 API 模拟的跨站登录与真实 Pi 回复验收。

兼容性：原咖啡方案的预置事件和数据结构保持原逻辑；新增独立导航分支。

当前实现支持文本模型输入，附件通过 MCP 上传适配转交，不假设模型有图像识别能力。

审核明细内嵌私人问答（2026-10-29）：提问只接受 question、clientMessageId 和 subjectId，
忽略浏览器附带的审核正文及其他用户身份。校验当前事项成员与连接组织后，由服务端统一

问题历史按用户、事项、工单隔离；普通私人问答不取入其他工单历史。上下文限长并标注裁剪，
