ANP

让财务 Agent 带着自己的身份跨环境工作

财务伙伴可以拥有独立的运行环境，再进入不同工作界面提供服务。它由财务个人或企业明确控制，拥有自己的身份、受控签名能力、私人记忆和授权记录。事项侧栏、审核页面、办公系统和移动端，都可以成为它的工作入口。

这里的“独立盒子”是一个可独立运行与管理的服务单元，可以部署在本机、企业服务器或受托云环境。得到明确委托后，它也可以在后台访问获准的业务系统，按约定频率和范围处理任务。

跨系统的共同基础与追溯路径

ANP 共同基础与跨系统授权跟踪

识别 Agent→验证身份→核对授权依据→本系统决定并执行→记录请求与回执→跟踪到期与撤销

建议把 Agent 身份、本系统授权记录、事项 / 请求标识和结果回执关联起来，能够回查：谁授权了谁，对哪份数据做了什么，以及结果是什么。

身份可复用，授权各自成立

财务 Agent 可以进入多个工作环境，并在明确授权下访问多个业务系统。ANP 提供身份认证与授权互操作的共同基础，业务系统与应用共同落实权限执行和记录关联。

“特殊权限”需要具体写成委托范围：允许访问哪些项目或账套、执行哪些动作、有效多久，以及如何撤销。涉及金额的操作，还要由执行系统核验额度与所需逐笔批准。

对 CFO 的价值：采购、审核和办公入口变化时，财务伙伴仍有明确归属；每个后台任务都能说明依据哪份委托、使用什么数据、允许什么动作，必要时可以停止后续授权使用并核查已发生的操作。

ANP 与业务系统分别承担什么

需要回答的问题共同机制与责任
这个请求来自谁ANP 的 DID 身份与认证机制支持跨平台验证请求主体；接收方核实身份材料和请求证明。
它代表谁，可以做什么授权机制表达委托或组织角色及范围。资源方确认授权依据、信任关系和本地策略，再决定可访问的资源与动作。
这次操作能否执行具体业务系统检查当前权限及所需批准；敏感动作需要绑定到本次操作的确认，不能仅凭已登录就执行。
发生了什么，何时停止Agent、授权服务与业务系统保留可关联记录，落实到期、撤销及结果核查。完整跨系统追踪需要产品与各系统共同实现。

规范边界：ANP-02 身份认证规范已发布，认证不自动授予业务权限。ANP-05 授权协议目前为未发布的 v0.7 草案，提出 DID 关联的 OAuth 授权与 VC 委托 / 组织角色凭证路径；各系统分别验证和决定接受范围。草案不代表当前 Demo 已实现这些能力。

02

页面上的两个 AI 分别帮什么忙

CFO 关心的问题 主聊天里的 TokenAI 右侧的财务经理 AI 伙伴
它在做什么 按日期、业务类型等查询授权工单，解释审核状态与明细 跟随事项讨论提供建议，也能在审核明细旁解释当前工单的规则、证据与风险
它依据什么 TokenX 返回的真实审核数据，加上事项里的对话 近期可见主聊天；针对工单提问时，加入服务端鉴权读取的审核数据和本工单私人问答
谁能看到 有权限进入同一事项的成员 当前登录用户本人
怎么使用 在主输入框提出业务查询 事项旁看分析、继续问答；审核明细旁可点“请 AI 解释这条规则”
能否处理业务 当前开放查询和查看结果 分析获准提供的工单数据、给出建议；审批与付款由具权人员按既有流程决定

右侧的自动分析会在主聊天处理完成后随讨论更新；私人问答保留自己的提问和回答。私人问题不会发到主聊天，也不会覆盖自动分析。在审核明细里提问时，服务端按当前权限读取所选工单，向伙伴提供审核上下文。不同工单的私人历史分别保存，刷新后可继续；重要判断仍应回到证据核实。

03

用一次合同付款查询走完整个过程

第一步 在共同事项里问事实

财务人员输入：“查询今天的合同付款审核明细。”主助手按当前授权范围查询，返回工单及可查看的审核结果。若需要跨日比较，可以明确指定日期范围。

第二步 看清规则和证据

选择“查看审核明细”，左侧先看整体结论、中文风险标签，再展开规则查看证据原文、引用、页码和处理建议。原始 JSON 收在默认折叠的技术详情里。需要留存时，可下载由真实审核数据整理的 Markdown 导出件；浏览器没有自动保存时，可点“保存文件”。

第三步 在明细旁问这张单

直接在明细右侧问：“这张单最需要关注什么？”也可以点击某条规则下的“请 AI 解释这条规则”，准备好问题后发送。伙伴会结合当前工单的真实依据回答，并显示本次工单读取时间。回答到达时，左侧已展开的规则与阅读位置保持不变。

05

CFO 需要把握的三个控制点

  1. 看得清范围：查询结果以当前账号和已连接数据的授权范围为准；结果为空时，先确认日期、业务类型和覆盖范围。
  1. 追得回依据：AI 的概括帮助快速阅读，重要结论回到工单明细、规则证据和审核结果确认。
  1. 留得住决定权：AI 可以整理事实与建议，财务经理及既有审批流程承担业务决定。后续开放修改类操作时，应逐项明确权限和确认机制。

今天现场怎么讲

“我们先在共同事项里查出真实工单，再打开审核明细。左边是规则和证据，右边是我的私人 AI 伙伴。看不明白哪条，就针对那条问；它结合这张单的依据解释，我再决定补什么材料、找谁复核。问答会保留，但不会自动发到事项群，最后仍按公司的流程作决定。”

“再往前一步，财务 Agent 可以拥有独立身份和运行环境，进入不同业务界面，在授权范围内后台处理任务。ANP 帮助跨系统认清这个 Agent 及其委托依据，各业务系统仍决定具体权限，并与应用一起关联授权和执行记录。”
