AWIKI INDUSTRIAL DATA SPACE · SOLUTION OVERVIEW

把产业数据空间、Agent 与既有企业服务，落到每个工作人员的“接单—协作—履约”过程里

这不是另建一个数据平台，也不是让每个参与方先变成 Agent。AWiki 作为场景工作面，由 AWiki 伙伴把可信数据空间的能力、企业系统、协作 Agent、专业 AI 应用与人的业务责任，组织进持续可追踪的事项。

为什么需要 AWiki整体架构业务闭环各方如何进入合规服务示例

要解决的不是“没有数据”，而是数据空间没有进入岗位的日常决策

化工供需协同中，需求、产能、质量、履约、风控和责任人分散在多个组织与系统。即使已有数据空间或 Agent，业务人员仍要自己判断：这单从哪里来、能否接、谁来确认、哪些信息能共享、出了问题谁处理。

◎
AWiki 伙伴将“可信连接”转成“可办理的工作”外部喊单不是自动成交；它先成为一件有目标、责任人、权限、证据、状态和回单的事项。Agent 可以建议、检索和执行，但不能越过人的业务承诺。

产品入口：消息管沟通，一览管变化，工作管持续办理

一级导航为“消息｜一览｜连接｜AWiki｜工作｜设置”。进入“工作”后默认打开事项，没有额外的首页层级。

MESSAGES消息

只保留私人会话、群会话和 Agent 消息；明确目标可转为或关联事项。

OVERVIEW一览

只保留 Inbox、动态、提醒与待处理变化；资源和专题不再混在信息流里。

WORK工作

默认进入事项，并可切换资源、专题、方案。方案是不同的工作能力包。

三层协同：底座可信、工作可办、能力可插拔

01 · TRUSTED FOUNDATION可信数据空间与身份授权

数据产品、DID、字段范围、用途、有效期与可验证 Receipt。原始 MES、成本、报价不因协作而自然外流。

02 · AWIKI WORK事项与人-Agent 协同工作面

把跨组织机会转换为持续事项：私人分析、人员决定、群内协作、Agent 指派、状态回写和证据保留。

03 · PLUGGABLE CAPABILITIESAgent、AI 应用、企业系统与专家

供需匹配、排产、合规、合同、物流、ERP/MES/DCS 或人工法务，都可在合适关口被调用。

演示中的一条完整业务闭环

页面并不把所有内容压进一个越来越长的聊天窗口，而是让每段协作在合适的事项中连续发生。

01 · REPORT工厂报送可信能力人员批准后，数据报送 Agent 从 ERP/MES/DCS 生成可承诺产能、窗口与质量等级证明。
02 · MATCH需求喊单与候选发现需求 Agent 提交签名需求；公共匹配服务只使用合规数据产品寻找候选工厂。
03 · DECIDE工厂判断是否接单AWiki 伙伴汇合产能、风险、质量和合作条件，供应商经理在事项中决定有条件响应、补证或暂缓。
04 · COOPERATE形成跨组织合作冻结双源组合、交付与质检框架；合同审核、报价隔离与责任边界进入合作事项。
05 · EXECUTE内部排产与履约回单各组织只接收本方任务投影；排产写回、物流、质检、签收和结算以 Receipt 回流长期事项。

AWiki 伙伴在中间，不替代任何一方

外部协作网络

  • 采购方与需求 Agent
  • 供需匹配服务
  • 其他工厂、物流与质检方
  • 数据空间与数据产品目录
AWiki 伙伴 / AWiki 工作面

面向具体责任人的事项

  • 把外部事件放入可追踪事项，而不是直接变成承诺
  • 右侧伙伴做私人分析，中间只记录共同事实
  • 用户确认 → 任务指派 → 受控执行 → Receipt 回单
  • 按事项投影上下文，不复制所有历史会话

海岳工厂内部

  • 供应商经理：接单条件
  • 生产计划：产能与排产批准
  • 数据责任人：对外投影边界
  • 法务 / 风控：合同与风险关口

事项让协作“可持续”，而不是一次性工作流

每一步只承接已确认的上游事实与必要证据索引；同一条业务线可跨多轮喊单、合作和履约持续运行。

DocPilot 在整体中的位置：专业风险能力，而不是被伪装的“合规 Agent”

它是本 Demo 证明“异构能力也能被 AWiki 伙伴编排”的例子。AWiki 伙伴不复制 DocPilot 的证据链、规则配置或人工审核界面。

D接单前：需求方资质与交易风险核验

收到喊单后，AWiki 伙伴在当前事项授权范围内把需求主体、必要附件、公开查询条件和用途交给 DocPilot。

AWiki 伙伴卡片预览：主体一致、未命中失信 / 被执行；2 项历史合同纠纷；缺少最新审计材料。
建议：可有条件响应，正式报价前补材料，首单分批交付并设置付款条件。

↗合作前：合同审核关口

双源供货方案冻结后，合同草案进入 DocPilot 的主体资格、公司信息、签字授权、权责和违约条款审核。

边界：服务结果可以形成风险建议与证据索引，但不能自动签约、自动付款，也不能替代法务的人工复核。

演示要传达的核心判断

“产业数据空间不是终端用户产品；它需要通过 AWiki 进入真实的岗位决策。在 AWiki 伙伴协助下，AWiki 不以封闭的多 Agent 系统为目标，而是把 Agent、应用、系统与人共同组织成可承担责任的工作网络。”— 化工产业协同贸易场景方案口径

演示数据说明：组织、订单、指标与风险结论均为虚构研讨数据。DocPilot 仅作为合作伙伴能力的脱敏接入示例，不包含其后台界面、真实客户信息或真实风控结果。
